# Third-eye · NeuronOS

**NeuronOS — a Personal Intelligence Operating System.** A living 3D knowledge graph where an AI layer helps you remember, think, decide, and execute — organized around your goals, not your files.

## Status

**Phase 1: Planning.** No application code exists yet, by design. The full product, architecture, design, and strategy documentation lives in [`docs/planning/`](docs/planning/00-INDEX.md).

Implementation begins only on the explicit instruction **"Begin Build Phase"** (see [Development Roadmap](docs/planning/13-development-roadmap.md)).
